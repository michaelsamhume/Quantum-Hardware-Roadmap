# Quantum Hardware Roadmap

### An Interactive Visualization of the Quantum Computing Landscape

An interactive web application designed to track, visualize, and compare advancements in quantum computing hardware across leading companies and research organizations.

Developed as part of my quantum computing research work with **Microsoft Quantum**, this project aims to make the rapidly evolving quantum hardware landscape more accessible, transparent, and understandable.

## Overview

Quantum computing is advancing rapidly, with companies pursuing different hardware architectures, scaling strategies, and approaches to fault tolerance.

The Quantum Hardware Roadmap brings these developments together into a centralized, interactive platform, allowing users to explore the current state of quantum computing and better understand the technological challenges that remain.

## Features

- **Interactive Hardware Roadmap:** Explore quantum computing developments and technological milestones.
- **Company Comparisons:** Examine hardware progress across organizations including IBM, Google, Microsoft, IonQ, Quantinuum, Rigetti, and others.
- **Hardware Metrics:** Compare technical indicators including qubit counts, gate fidelities, coherence times, and gate speeds.
- **Fault-Tolerance Tracking:** Explore progress toward error correction and fault-tolerant quantum computing.
- **Interactive Visualizations:** Navigate hardware data through an accessible, browser-based interface.
- **Research Commentary:** Support discussion and contextual analysis of developments in quantum computing.

## Technologies

- **HTML5, CSS3, JavaScript** — Application interface and interactive functionality
- **Supabase** — Backend services for shared commentary
- **Netlify** — Static web application deployment

## Getting Started

Clone the repository:

```bash
git clone https://github.com/michaelsamhume/Quantum-Hardware-Roadmap.git
```

Navigate into the project directory:

```bash
cd Quantum-Hardware-Roadmap
```

Open `index.html` in a modern web browser to explore the application.

Some functionality, including shared commentary, requires access to the configured Supabase backend.

## Motivation

Quantum computing has the potential to transform fields ranging from materials science and chemistry to optimization and artificial intelligence.

However, comparing developments across different hardware architectures and companies can be challenging, particularly when technical information is distributed across research papers, company announcements, and hardware specifications.

I built this project to help bridge that gap by translating complex scientific information into an intuitive and interactive experience.

The project reflects my broader interest in developing software that makes emerging technologies more accessible and supports scientific research.

## Research Background

This project was developed in the context of my research internship with Microsoft Quantum, under the supervision of Hariharan Raghunathan, Principal Software Engineer at Microsoft, and in collaboration with Professor Matthew Otten at the University of Wisconsin–Madison.

The experience strengthened my interests in scientific computing, software engineering, and the intersection of emerging computing technologies.
